# Ekghor

All your messengers in one window — WhatsApp, Messenger, Telegram, Instagram and more.

## Download

Get the latest **Ekghor-Setup-x.y.z.exe** from [Releases](https://github.com/AJAHARUDDIN1997/ekghor-releases/releases/latest).

Once installed, Ekghor updates itself: it tells you inside the app when a new version is out.
